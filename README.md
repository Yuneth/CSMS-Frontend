# Project Name: Cleaning Service Management System - Admin Panel (CRUD)

## Core Features

### User Functionality:

### Register and Login to the system
### Book a Cleaning Service
### View and Manage Bookings

## Setup Instructions:

### Backend: Spring Boot

### Database: MySQL

### Frontend: React.js with Material UI

### API Client: Axios

### Authentication: JWT

### Java version: 17

### Database: cleaning_system

### Form handling and validation: formik + yup



### Download and open it in VS Code

### Open New Terminal

### Type: npm install {for Install node module}

### Finally, Type: npm start
